6 Key Changes Explained

1

Collapse the keyboard

11 equal-weight buttons → 3–4 prioritized rows. Primary action dominates. Everything else behind More.

Before: 5 rows, 11 buttons, no hierarchy
After: 3 rows, primary elevated
2

Job card format

Structured card with visual hierarchy: title → match % badge → company → bullets → posted date. Scannable in under 3 seconds.

Before: wall-of-text prose block
After: scannable card with clear sections
3

Home screen copy

Replace the "best path" documentation language with a product-oriented dashboard: name, role, four primary commands clearly labeled.

Before: "Use next to review one fresh match..."
After: "Fresh AI-matched roles for Teja"
4

Visual differentiation

Apply gets a success-green tint, Skip gets muted styling, Next gets a primary-color call-to-action weight. Color communicates intent without extra text.

Before: every button identical weight
After: color + weight hierarchy
5

Match badge on card

88% match displayed as a compact inline badge next to the job title. User instantly knows relevance before reading anything else.

Before: "Match Score: 88" buried in prose
After: prominent badge at the top of card
6

Next at the bottom

After reviewing a job card, "Next Match" sits at the bottom — the natural continuation action. Thumb-reach placement on mobile.

Before: Next hidden among equal buttons
After: prominent bottom CTA after card

My Assessment vs. ChatGPT

Fully agree with ChatGPT

  • Too many equal-priority buttons is the #1 UX problem. Cognitive overload is real even at 11 buttons.
  • Job card redesign is the highest-ROI change. Structured card vs. prose block is a massive readability improvement.
  • Home screen copy needs to be product-oriented, not command-manual language.
  • No backend changes needed for these wins — pure message formatting + keyboard JSON config.
  • Progressive disclosure via "More" is the right pattern for Telegram's limited UI.

I'd add to ChatGPT's plan

  • Match % badge placement matters more than copy. Put 88% on line 1 of the card, not buried in bullets.
  • Context-sensitive keyboards: keyboard should change based on state (browsing vs. reviewing a card vs. drafting).
  • Inline emoji as icons (⟶ Next, ✓ Apply) improves scannability in Telegram's monospace-adjacent font without any custom markup.
  • Bot status indicator ("● Active") sets a product tone immediately — small but worth doing.
  • Skip confirmation flow: "Skip" should ask for a reason (1-tap: too senior / wrong stack / already applied) — this trains your matching engine passively.
